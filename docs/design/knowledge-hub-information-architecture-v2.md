# 知识中心信息架构与学习编排 v3

最后复核：2026-09-10

状态：`COMMERCIAL_IA_IMPLEMENTED_AND_LOCALLY_VERIFIED`

## 1. 问题判断

旧知识中心拥有 603 条内容和 6 个专题，但页面主要按内容库存组织：

- 内容数量和专题数量被拆成数字与单位，无法形成完整统计语义；
- 左侧“学习顺序”与右侧“从这里开始”来自两套筛选逻辑，用户不知道两者如何对应；
- 六个现实专题使用相同图片、相同标题模板和相同摘要句式，主题识别不足；
- “报告阅读”通过标题和摘要关键词自动抓取，混入提问、AI、保存和边界等不同目标；
- 完整资料库默认展示大量异质条目，把筛选和排序成本交给用户。

根因不是内容不足，而是内容库存没有转化为课程、专题和查找任务。

## 2. 用户进入知识中心的三个一级目标

知识中心第一层只保留三个无需理解内容类型的用户目标：

1. 从这里开始：覆盖第一次使用和正在阅读报告的用户，进入提问、起卦、报告阅读和可信边界；
2. 按现实问题：进入当前有内容纵深的六个问题专题；
3. 深入理解：进入角色、旺衰、动变、冲突、时间和图解知识。

“已有报告”不再与入门路径争夺一个一级目标，而是在页面中保留固定四步阅读区。全部资料是查找工具，不是第四种学习目标。用户不需要先理解教程、知识卡、FAQ、术语等内容类型。

## 3. 当前五阶段学习路径

学习路径是一个联动组件，不是左右两套入口：

| 阶段 | 用户目标 | 内容范围 |
| --- | --- | --- |
| 01 | 先知道怎么使用 | 适用问题、提问方法、可信边界 |
| 02 | 理解起卦与盘面 | 阴阳动静、本卦变卦、排盘结构 |
| 03 | 看懂角色与关系 | 用神、六亲、世应、关系结构 |
| 04 | 判断力量与时间 | 旺衰、动变、冲突、时间提示 |
| 05 | 进入现实问题 | 感情、事业、合作、财务、出行 |
| 06 | 练习阅读报告 | 结论、依据、冲突与保守表达；当前案例内容为内部审核态，不作为公开阶段 |

页面根据 Runtime 可见内容动态展示阶段。当前本地可学阶段为 5 个，每次只显示当前阶段前三篇，并给出“从本阶段第一篇开始”。第 6 阶段只有在案例内容解除内部审核门槛后才出现。移动端正文保持单列。

## 4. 现实问题专题

专题名称不使用“用六爻整理 XX 中的现实决策问题”模板，改为用户可以直接识别的名称：

- 感情与关系；
- 合作与项目；
- 事业与工作；
- 资金与财务；
- 考试与求职；
- 出行与计划。

房产与居所、寻物与物品、纠纷与协商、健康与恢复保留资料和路由能力，但不进入一级专题导航，并保持 noindex，直到各自拥有足够内容纵深和专业安全审核。

每个公开专题必须配置：所属首页场景类别、自然语言简介、三条示例问题、四个主题观察维度、首页起卦场景和专属任务视觉。专题列表与专题详情共用同一份 `topicProfiles`，避免名称、图片和 CTA 漂移。

专属任务视觉不能只替换标题与节点文字。六个公开专题分别使用关系场、投入平衡、分叉决策、资金循环、聚焦靶盘和节点路线，使用户在阅读卡片文字前就能区分问题类型。隐藏专题仍需保留对应安全边界，不能因为存在页面就自动进入主导航。

## 5. 学习合集

12 套学习合集属于“围绕一个目标连续学习”的二级产品层，不占用一级导航。知识首页只展示四个代表性入口，完整合集页按“开始使用、理解盘面、建立判断、现实应用”分组。每套合集固定包含适用人群、学习结果、预计时间、三篇推荐顺序和前后合集导航；只有三篇内容均满足当前 Runtime 可见性时才显示。

## 6. 报告阅读

报告阅读不再根据关键词自动聚合。固定顺序为：

1. 先确认报告在回答什么；
2. 分开看支持与阻碍；
3. 再看变化与时间；
4. 最后核对专业依据。

每一步只绑定一篇明确教程。专业内容处于第四步，不与总体判断争夺第一注意力。

## 7. 完整资料库

完整资料库属于按需查找层：

- 默认选择“入门与边界”，而不是一次展示所有内容；
- 可按七个学习模块切换，另提供“全部内容”；
- 支持搜索具体术语或问题；
- 每次显示 18 条，并由用户主动加载下一组；
- 列表同时显示标题与两行摘要，降低逐条打开成本。

内容类型仍作为元数据保留，但不再承担主要导航职责。

## 8. 验收标准

- 内容统计必须以完整短语呈现，不能拆开数字与单位；
- 三个用户目标入口在首个内容屏内同时可见；
- 当前五个阶段与右侧三篇内容保持联动，第六阶段不得绕过审核门槛；
- 六个公开专题使用六张不同且对应主题任务结构的视觉，隐藏专题不进入主导航；
- 12 套合集在本地审核环境都有目录和详情路由；生产环境仅在三篇关联内容都通过发布门槛后展示；
- 专题列表和详情不显示原始模板标题；
- 报告阅读固定为四步；
- 资料库支持按模块、形式、深度和关键词组合筛选，首次只显示 18 条；
- 360、390、430 和桌面宽度无页面级横向溢出；窄屏中三个目标和五个知识导航入口无需横滑即可识别。

## 9. 后续约束

- 新专题必须先补 `topicProfiles`，不能复用无关专题图片；
- 课程入口必须由显式内容 ID 编排，不能通过标题或摘要关键词自动拼接；
- 首页负责引导，完整资料库负责查找，二者不得同时展示大量内容；
- 内容总量增长不能直接导致首页卡片数量增长；
- 新增首页场景必须同步补齐专题模型、专属视觉、问题示例、观察框架和安全边界，不能只增加入口名称。
- Learn Hub、Library、Topic、Collection、Public API 与 sitemap 必须共同使用 Runtime 发布状态，不能各自维护可见性名单。
- 开发环境可以显示 `REVIEW_REQUIRED` 供本地验收；beta/production 只能显示 `PUBLICATION_READY`。
