# 61｜核心用户价值、范围与停止线

## 产品目标
首版不追求复刻所有传统六爻细则，而是稳定解决六个用户问题：
1. 当前局势；2. 对自身是否有利；3. 支持因素；4. 阻碍因素；5. 变化方向；6. 候选时间窗口。

## 三层能力
- 确定性排盘：完整实现，不可精简。
- 核心判断：只启用 CORE_V1 白名单。
- 高级判断：保留数据，但默认关闭。

## 停止线
满足以下条件立即停止继续补规则，进入 Public Beta：
- 确定性排盘 fixture 全通过；
- 45 个高频问题映射可用；
- 148 个生产单元可追溯；
- 每次报告稳定压缩为 6–12 个关键证据；
- AI 失败时仍可输出结构化基础报告；
- 不出现明显前后冲突。

## 只有以下证据可以触发扩展
- 同一类用户反馈持续出现；
- Golden 案例证明存在稳定漏判；
- 专家完成规则边界审核；
- 新规则能量化改善报告质量。

“传统资料中存在该规则”本身不能成为开发理由。
