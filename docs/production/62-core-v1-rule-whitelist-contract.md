## 执行规则
1. 生产环境只加载 `core-v1-*.json`。
2. 原 `*-pro.json` 仅作为候选总库，不得直接全量加载。
3. 任意 `REVIEW_REQUIRED` 规则不得通过配置继承、通配符或 fallback 进入生产。
4. 事实、信号、候选时间必须使用不同 output role。
5. 用神映射如出现语义歧义，要求用户确认问题类型。
6. 健康与法律场景不得输出诊断、治疗或法律裁决。

## Release Tier
- `CORE_V1`：默认启用。
- `ADVANCED_BETA`：仅内部/专家灰度。
- `REVIEW_REQUIRED`：禁止执行。
- `DEPRECATED`：不再采用。

## 重要边界
白名单批准的是“产品首版使用范围”，不是对传统术数预测有效性的科学背书，也不代表所有复杂结论已经专家 Golden 验证。
