# 65｜CORE_V1 验收标准

## 数据
- 生产单元必须在 100–150 之间；当前为 148。
- 生产白名单中 `REVIEW_REQUIRED` 数量必须为 0。
- 所有白名单 key 必须能在候选总库中定位。

## 引擎
- 不允许从总库通配加载。
- 每条 finding 保存 rule code、输入事实、版本、output role。
- AI 不得创建未命中的 finding。

## 报告
- 6 个用户价值维度可生成。
- 证据推荐 6–12，硬上限 15。
- 应期仅输出候选窗口与依据。
- 健康/法律场景显示安全边界。

## 发布状态
通过本验收后可标记 `PUBLIC_BETA_SCOPE_READY`，不能仅凭本包标记完整专业数据或 `PRODUCTION_READY`。
