# 首页：提问优先设计与验收

更新：2026-09-06。范围为首页及公开报告示例，不表示全站商业发布验收通过。

## 核心路径

- 第一屏直接填写问题并开始起卦，不先看宣传屏，不强制选择场景。
- 六个核心场景直接显示在输入框上方：感情关系、工作事业、合作创业、财务收支、学业考试、生活事务。图标、名称与选中描边共同标识，不依赖颜色辨认。
- 选择场景在原位置展开典型问题，点击示例才填入并聚焦输入框。初始不强制选择，可再次点击取消。切换场景不会覆盖原问题，也不会更改其问题理解；提交数据不含所选场景分类。
- 生活事务下以选择框提供居所、出行、寻物、法律纠纷和健康恢复，法律与健康显示相应专业服务边界。感情提供关系推进、复合和沟通问题，合作同时覆盖创业经营。
- 必要追问沿用真实模型问题理解，出现追问时隐藏其他开始操作和问题示例。
- 手动摇卦和录入已有卦爻保留，但不抢占主操作。
- 报告示例和学习各有独立入口。首页导航不再重复显示一个只负责滚动的“开始分析”按钮。

## 视觉与信任

- 移除首页旧版宣传图和“方向、关键点、下一步”重复说明；第一屏优先展示实际可操作的输入框。
- 字号按组件设定，不随视口宽度缩放。首页区块为分隔线与开放布局，不使用大卡片包裹页面。
- 下方显示真实计算的六爻图及同一份真实模型回答，并可打开完整示例、卦象说明、关键依据、取舍与建议。
- 不展示“事实已核对”。原有两张历史资产标记为“历史版式示意”，不再作为首页或社交预览使用。
- 示例如实说明：演示问题、真实模型生成，不是真实用户个案、不代表来访者的结果；盘面解释不等于现实事实已经核验。

## 示例来源

`apps/web/app/example/report.json` 来自本地真实模型冒烟测试创建的合成问题，仅供演示。

导出脚本 `scripts/ai/export-home-example.ts` 核对预期测试问题、真实 provider 和有效结果，只保存可见卦盘视图与解读。不公开用户报告、凭据或本地报告地址。完整页面 `/example` 是版本化静态内容，不依赖数据库报告 ID，刷新及迁移后仍可用，也不会在访问时消耗模型额度。

如需刷新示例，先运行真实模型冒烟，再运行：

```sh
node --import tsx scripts/ai/export-home-example.ts
node --import tsx --test tests/home-example.test.ts
```

更换示例题材时，需同时审核导出白名单、首页摘要标题和图示状态；不能把任意用户报告导入公开示例。

## 草稿与验收

问题与补充信息在当前标签的 sessionStorage 中保留 30 分钟。刷新或浏览示例回来后恢复；成功创建报告后清除。关闭标签后不主动持久化，禁用存储仍可使用主流程。卦爻录入不属于此次草稿范围。

本轮浏览器核对：手机宽度 390（内容区 375）时输入框顶端约 297px，提交按钮底端约 618px，均进入首屏；旧版输入框顶端约 1018px。实际尺寸会随系统字体、浏览器工具栏变化。

后续恢复可选场景入口后，手机采用三列两行，桌面采用六列；未展开示例时场景、输入框和提交按钮仍在首屏内。上述 297px 数据属于恢复场景前版本，不是最新布局尺寸。

检查包括示例填入与聚焦、刷新草稿恢复、真实模型必要追问时仅一个主操作、完整示例与依据入口，以及桌面和手机无横向溢出。没有用这些检查替代真实用户转化率与理解度测试。

补充验收：从新版首页提交关系问题、澄清为恋爱关系，成功创建新报告并完成真实 AI 解读；首页学习配图加载正常。`pnpm run test:home` 的三项契约测试及 Web TypeScript 检查通过，Web lint 无错误，保留一项既有未使用函数警告。
