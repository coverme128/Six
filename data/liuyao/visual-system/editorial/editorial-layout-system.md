# Editorial Layout System

Editorial assets inherit product tokens but may use more atmosphere.

- Article/Learn: 60% analytical/editorial structure, 40% cultural atmosphere.
- Topic landing: strong task hierarchy; decorative image never pushes CTA below first useful viewport.
- Case: clearly marked 教学示例 / EDUCATIONAL_EXAMPLE.
- Trust: system diagrams > mystical imagery.
- Social: one idea per frame; source content ID preserved in metadata.
