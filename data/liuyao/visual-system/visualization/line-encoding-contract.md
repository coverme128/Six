# Line Encoding Contract

## Yin / Yang
- Yang: continuous line.
- Yin: two separated segments.
- Yin/Yang are structural properties, not good/bad states.

## Moving / Static
Moving state requires at least two encodings among:
- marker,
- line treatment,
- text label,
- semantic motion.

## Shi / Ying / Yongshen
Use explicit labels (世 / 应 / 核心观察对象) and optional restrained semantic accents. Never use color alone.

## Ordering
Visual vertical order is always 上爻 at top -> 初爻 at bottom. Casting sequence progresses 初爻 -> 上爻.
