# Responsive Contract

## Desktop Professional
- six-line board may show full columns with side evidence panel;
- primary and changed hexagram can be side-by-side;
- hover may supplement but never replace click/focus;
- keep formal labels when space permits.

## Tablet
- keep vertical six-line structure;
- collapse secondary metadata into side sheet;
- primary/changed may become stacked when width is constrained;
- reduce simultaneous labels.

## Mobile Guided
Never mechanically shrink the desktop board.

Default six-line row displays only:
- line geometry,
- moving/static marker,
- key role / core focus when relevant,
- Shi / Ying label,
- important state indicator.

Tap line -> Bottom Sheet details. Minimum touch target 44px.

## Mobile Professional
Use layer switcher:
- Core
- Roles
- State
- Dynamics
- Evidence

Do not render 8–10 metadata columns in a 360px-wide row.

## Export
Static export uses a dedicated renderer/viewBox. Never rely on browser screenshots as the canonical export path.
