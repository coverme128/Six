# Accessibility Contract

Target: WCAG 2.2 AA for core visual interaction.

Required:
- semantic labels for every line/node/edge that communicates meaning,
- keyboard-selectable interactive lines and evidence nodes,
- visible focus,
- 44px touch targets where interactive,
- color + label/shape/position redundancy,
- screen-reader summary before dense visualization,
- reduced-motion path,
- no auto-playing decorative motion,
- text equivalents for relation direction, uncertainty and selected states,
- PDF/static legends embedded.

Hexagram line accessibility example:
`四爻，阴爻，动爻，世爻，本次核心观察对象，存在制约；可展开查看依据。`
