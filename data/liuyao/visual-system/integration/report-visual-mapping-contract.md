# Report -> Visual Mapping Contract

Report visual priority:
1. main result / core board,
2. core focus / relationship,
3. change / support-risk,
4. timing,
5. evidence / pattern on demand.

Guided default: 2–4 meaningful visuals maximum in the main report flow. Professional may expose more layers but should not become a wall of diagrams.

Each visual must receive facts already resolved by ProductResultFacts / Presenter. Visual components never arbitrate conflicting rules.
