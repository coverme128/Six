# Typography and Layout

## Typography
- UI: system sans / Geist / Inter-compatible; Chinese UI: Noto Sans CJK / Source Han Sans compatible.
- Editorial: restrained serif may be used for long-form titles, cultural context and quotations.
- Calligraphy: rare accent only; never body copy or data labels.
- Product body text: >= 14px; dense Professional metadata: >= 12px only when paired with expansion/detail access.

## Layout geometry
- Core hexagram geometry is vertical and bottom-origin aware: 初爻在下，上爻在上.
- Maintain strong alignment between primary and changed hexagram columns.
- Use whitespace to separate semantic layers before adding borders.
- Never compress 8–10 professional fields into a single mobile row.

## Density
Guided = core task meaning first. Professional = more fields, same facts. Educational = explanatory annotations allowed. Static export = deterministic, legend included.
