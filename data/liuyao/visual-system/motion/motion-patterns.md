# Motion Patterns

## MOT-LY-01 Line Focus
Selected line strengthens; unrelated layers reduce; linked evidence appears. 160–320ms.

## MOT-LY-02 Casting Build
Initial -> second -> ... -> top line. Sequential construction communicates bottom-to-top causality. 480–800ms total or user-stepped.

## MOT-LY-03 Moving Line Transformation
A supplied moving line transitions to its supplied changed line. Animation explains a fact; it never calculates one. 320–480ms.

## MOT-LY-04 Evidence Path
Fact -> relation -> Finding -> result explanation. 420–600ms.

## MOT-LY-05 Timing Reveal
Timeline baseline -> candidate windows -> uncertainty marker. 360–600ms.

## MOT-LY-06 Guided -> Professional
Preserve selection and spatial context; reveal more layers without recalculation. 280–480ms.
