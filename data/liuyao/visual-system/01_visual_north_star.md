# 01 — Visual North Star

## Brand sentence
**Traditional Chinese divination structure, modern decision interface.**

## Official style name
**Modern Eastern Analytical**  
中文：**现代东方分析视觉体系**

## Product visualization metaphor
The Liuyao product should feel like a **modern relationship-and-change analytical instrument**.

Core visual metaphors:
- six-level vertical structure,
- line rhythm,
- lower-to-upper casting order,
- primary → changed transformation,
- relationship edges,
- evidence paths,
- temporal windows,
- progressive analytical density.

## Four required qualities
1. **Professional** — precise, calm, evidence-oriented, legible.
2. **Eastern** — expressed through proportion, line rhythm, restrained palette and compositional balance, not decorative clichés.
3. **Analytical** — hierarchy before ornament; relationships, uncertainty and state changes are visible.
4. **Editorial** — strong rhythm, whitespace and selective imagery.

## Product / editorial balance
- Product visualization: 85–90% analytical / 10–15% cultural atmosphere.
- Learn / article visuals: ~60% structure / 40% editorial atmosphere.
- Marketing hero: atmosphere may rise to 50–60%, while shared geometry and palette remain.

## Forbidden directions
- red/gold fortune-telling advertising,
- glowing Bagua / magic circle / occult particles,
- xianxia game UI,
- heavy parchment or fake antique surfaces,
- giant 吉/凶 stamps,
- color-only good/bad semantics,
- luxury black-gold mysticism,
- excessive calligraphy,
- pseudo-scientific scores not backed by formal facts.

## Information priority
Guided default:
1. overall result / current task,
2. core focus,
3. Shi/Ying or key relationship,
4. moving/change information,
5. main support / constraint,
6. timing hint,
7. action.

Professional:
1. complete structured line fields,
2. roles / Yongshen / Shi-Ying,
3. strength and special states,
4. dynamic relations,
5. pattern / evidence / timing,
6. provenance and verification help.

Professional does **not** mean developer debug. Raw JSON, DB IDs, prompts, provider traces and internal enums stay out of user views.
